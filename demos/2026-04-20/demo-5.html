🧬 Skill Compile Detector

繰り返す作業を自動検出 → 再利用可能な「スキル」にコンパイル
痛み (研究発想): LLMエージェントは昨日うまくいったタスクを今日もゼロから推論。人間も同じ — 同じ作業を毎回思い出しながらやり、学習が積み上がらない。
価値: 論文「SkillDroid」の中核（成功した手順をテンプレート化して再利用）を日常業務に適用。3回繰り返した瞬間に「これ、テンプレ化すれば次は1タップ」を自動通知。
本番版で追加される機能:
・ブラウザ拡張で実際の操作を記録 (URL / クリック / 入力)
・Claude API でテンプレートのスロット (日付 / 顧客名など) を自動検出
・ワンクリック実行 (次回は完全自動で同じ手順を再生)
・チームで共有 — メンバー全員の「暗黙知」がスキル化
